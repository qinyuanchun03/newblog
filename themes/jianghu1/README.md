# My Hexo Theme

This is a simple Hexo theme.

## Installation

1. Clone this repository into the `themes` directory of your Hexo project:
   ```bash
   git clone https://github.com/your-username/my-theme.git themes/my-theme
   ```
2. Update your Hexo `_config.yml` to use this theme:
   ```yaml
   theme: my-theme
   ```

## Configuration

The theme's configuration is located in `_config.yml`. You can customize:

- `menu`: Navigation links
- `social_links`: Social media profiles
- `disqus_shortname`: Disqus comments integration
- `footer_links`: Links in the footer

## Development

To develop this theme, you'll need Node.js and Hexo CLI installed.

1. Navigate to the theme directory:
   ```bash
   cd themes/my-theme
   ```
2. Install dependencies (if any, though this theme is minimal):
   ```bash
   npm install
   ```
3. Run Hexo in development mode from your main Hexo project directory:
   ```bash
   hexo server
   ```
